Retirer la commande trema ui (tunnel SSH)

Pas de description. Je lis « Trima UI » comme la commande CLI trema ui. Elle ouvre un tunnel ssh -L 4000 puis le navigateur sur http://localhost:4000. Depuis T-7, trema ui:install expose toujours l'interface sur https://trema.<host> (mot de passe + TOTP). La commande ne sert donc plus à rien : on la retire, avec la doc et les messages qui y renvoient. Le tableau de bord lui-même ne change pas.

Périmètre proposé

  • CLI bin/trema : on retire la fonction ui(), l'entrée ui) du dispatcher et la ligne trema ui de l'aide. Le message de fin de ui:install n'affiche plus que l'URL HTTPS.
  • Docs : dans le README (section « Interface web ») et docs/architecture.html, l'accès se fait par https://trema.<host>. La phrase « Par le tunnel SSH, aucune connexion n'est demandée » est reformulée ou retirée, selon Q2 et Q3.
  • Inchangé (reco) : le serveur continue d'écouter sur 127.0.0.1:4000 derrière nginx. L'accès en boucle locale sans login reste en place, car le dev (npm start + Vite) en a besoin et il sert de secours par ssh -L manuel (Q3). ui:password ne change pas.
  • Hors périmètre : toute modification du front React, de l'authentification ou de nginx.
