Onglet Source : la config d'une app s'affiche sur une autre

Bug front uniquement. Le serveur renvoie la bonne config ; c'est le formulaire qui garde l'état de l'app précédente.

Cause

Dans App.tsx, <SourceTab app={app.name} /> n'est pas remonté quand on change d'app : React réutilise le même composant, donc l'état local form (dépôt, branche, dossier racine, cases) et branches survivent au changement d'app.

Le seul « recalage » est useEffect(() => { if (src.data) setForm(src.data) }). Il ne s'applique pas quand :

  • la nouvelle app n'a pas de source (src.data === null) → on garde à l'écran la config de l'app précédente, et un clic sur « Enregistrer » l'écrirait sur la mauvaise app ;
  • la source de la nouvelle app est en cours de chargement (pas en cache) → l'ancienne config s'affiche le temps de la requête.

L'onglet Env a déjà un reset explicite sur [app], il n'est pas concerné. Les onglets Vue d'ensemble / Logs / Déploiements n'ont pas d'état de formulaire.

Prototype (simulation)

« api » a une source configurée, « blog » n'en a pas. Cliquez sur les apps dans la sidebar en mode Avant puis Après.

Correction proposée

A. Remonter l'onglet à chaque app (recommandé)

Ajouter key={app.name} sur les composants d'onglet dans App.tsx. Tout l'état local repart de zéro : formulaire vide, puis rempli par la source de l'app (depuis le cache, ou au retour de la requête). Une ligne, couvre aussi tout futur onglet avec état.

B. Reset ciblé dans SourceTab

Réinitialiser form / branches sur changement de app, et quand src.data === null. Plus local, mais à refaire pour chaque nouvel onglet.
Bonus proposé : tant que la source de l'app n'est pas chargée, afficher un squelette plutôt qu'un formulaire vide, et désactiver « Enregistrer » — pour éviter tout écrasement accidentel.

Critères d'acceptation

  • Passer de « api » (source configurée) à « blog » (sans source) affiche un formulaire vide.
  • Passer de « api » à « shop » n'affiche jamais, même brièvement, les valeurs de « api ».
  • La liste des branches correspond au dépôt de l'app affichée.
  • « Enregistrer » ne peut pas écrire la config d'une autre app.
